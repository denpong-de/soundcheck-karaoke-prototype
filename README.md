# Soundcheck Smart Songbook — Interactive Prototype

Prototype เว็บแอปมือถือ/iPad สำหรับห้องคาราโอเกะ: สแกน QR ในห้อง → ค้นหาเพลง (ไทย สากล เกาหลี ญี่ปุ่น, ค้นด้วยเสียงได้) → ต่อคิวร่วมกันหลายคน → ปรับคีย์/เสียงดนตรี/เสียงนักร้อง → สั่งเครื่องดื่มและอาหาร

> **หมายเหตุ:** งานนี้เป็น Prototype เพื่อการศึกษา (วิชาในหลักสูตรปริญญาโท) ไม่ใช่เชิงพาณิชย์ และไม่ใช่ผลิตภัณฑ์หรือเว็บไซต์ทางการของ Soundcheck
> ชื่อ โลโก้ และสีแบรนด์ Soundcheck เป็นของเจ้าของแบรนด์ ภาพปกอัลบั้มเป็นลิขสิทธิ์ของค่ายเพลงและศิลปินเจ้าของผลงาน
> ข้อมูลเพลงและเมนูเป็นข้อมูลตัวอย่าง ไม่มีเสียงหรือเนื้อเพลงจริง และไม่ได้เชื่อมต่อซอฟต์แวร์จอคาราโอเกะจริง
> หากเจ้าของลิขสิทธิ์ต้องการให้ถอดเนื้อหาใด กรุณาแจ้งผ่านหน้า Issues ของ repository นี้

## วิธีใช้
- บนคอมพิวเตอร์จอกว้าง (≥ 1400 px): แสดงมือถือ 3 เครื่องเพื่อเดโมหลายคน พร้อมแผงปุ่มช่วยพรีเซนต์
- บน iPad: เลย์เอาต์แบบ Spotify / Apple Music
- บนมือถือ: แอปเต็มจอ (เติม `?demo=1` ท้ายลิงก์เพื่อเปิดปุ่ม DEMO)
